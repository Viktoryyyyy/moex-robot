# USDRUBF breakout and pullback research — 2026-10-06

[Основной отчёт на русском](../../docs/research/usdrubf_breakout_pullbacks_2026-10-06.md)
содержит выводы, допущения, ограничения и отдельный внутридневной разбор.

## Состав

- `summary.json`: сводные результаты по направлениям, периодам и контекстам.
- Полный журнал 179 событий × 26 правил остаётся локально и не публикуется.
- `robustness.json`: проверки, чувствительность и bootstrap на 46 окнах.
- `protocol.json`: протокол для воспроизведения. Уточнено только описание
  исполнения заявки при гэпе: уже стоящая заявка исполняется и при пересечении
  стопа сразу закрывается с издержками. Это соответствует исходному коду;
  численные результаты не изменены.
- `input_manifest.json`: контрольные суммы внешних входов и исходного Excel.
- `intraday_followup.json`: отдельный снимок и сценарии на 16:10 мск 6 октября.
- `study.py`, `confirmed_levels.py`, `validate.py`: воспроизводимый расчёт.
- `check_results.py`: проверка агрегатов без подписки и внешних входов.

## Проверить опубликованные результаты

Из корня репозитория, Python 3.11 или новее:

```sh
python research/usdrubf_breakout_pullbacks_20261006/check_results.py
```

В `summary.json` опубликованы агрегаты по всем 26 правилам для семи групп,
без отдельных событий и исходных свечей. Пустой вход учитывается нулём
на исходный сигнал. Подробные данные исходного исследования остаются локально.

## Повторить расчёт на исходных входах

Полные данные AlgoPack остаются вне публичного репозитория. В каталоге
`PRIVATE_INPUT_DIR` должны находиться три файла из `input_manifest.json`:
`update_oct06_rows.json`, `pullback_bars.json`, `pullback_funding.json`.
Это замороженные экспортированные данные существующих инструментов проекта,
не новые источники или автоматически меняющаяся выборка. Перед расчётом
проверяются SHA-256 всех трёх файлов и затем сверяются дневные OHLCV.

```sh
python -m pip install -r research/usdrubf_breakout_pullbacks_20261006/requirements.txt
python research/usdrubf_breakout_pullbacks_20261006/validate.py --input-dir PRIVATE_INPUT_DIR --output-dir LOCAL_OUTPUT_DIR
python research/usdrubf_breakout_pullbacks_20261006/check_results.py --rerun-dir LOCAL_OUTPUT_DIR
```

`LOCAL_OUTPUT_DIR` должен отличаться от каталога исходных данных и находиться
вне отслеживаемого дерева. `validate.py` выполняет основной расчёт,
проверяет причинность сигналов и исполнение, затем рассчитывает чувствительность.
Последняя команда сравнивает воспроизведённые агрегаты и проверки
с опубликованными результатами. Полный журнал создаётся только локально.

Расчёт не обращается к сети, не размещает заявки, не меняет рабочий Excel
и не зависит от локального адреса сервера или учётных данных. Данные после
закрытия 5 октября не участвуют в историческом сравнении правил.
