# USDRUBF: многосессионная разворотная модель 5m/D

Статус: `RESEARCH_ONLY`. Данные: 195 068 нативных баров AlgoPack 5m, 1 180 наблюдаемых сессий с 2022-04-26 по 2026-11-09. Решение: **отклонить для forward-пилота**.

Исследование изолировано от frozen EMA 3/38, действующего однодневного монитора, paper-пилота, манифестов и автоматизаций. Оно не меняет их код, конфигурацию или расписание.

## Протокол и отсутствие look-ahead

Финальный holdout `2026-10-01..2026-11-09` был закрыт до ранжирования вариантов. Walk-forward состоит из трёх непересекающихся проверок: 2025 год, первое полугодие 2026 года и третий квартал 2026 года. Сделка, пересекающая границу fold, исключается. Приоритет задаётся весами 1/2/3, поэтому свежие периоды важнее 2025 года. Правила не подбирались под движение 26 октября — 9 ноября.

OHLC D строится только из уже завершённых 5m-сессий. Официальная D-история ISS используется для `SWAPRATE`. Базовые издержки равны 0,025 пункта на сторону, как в frozen EMA 3/38; это 25 RUB на контракт на сторону при множителе 1 000. Стресс — 0,05 пункта на сторону. Финансирование списывается или начисляется по фактическому знаку `SWAPRATE`; отсутствующее значение получает неблагоприятную оценку, а не ноль.

## Проверенные правила

После закрытия сессии новый минимум относительно пяти предыдущих наблюдаемых сессий создаёт long setup, новый максимум — short setup. Setup действует следующие 3 или 5 сессий. Новый экстремум того же направления после закрытия сессии заменяет старый setup; истечение срока, исполнение, конфликт двух направлений и риск более 3 ATR отменяют вход.

Проверены пять подтверждений:

1. касание `high setup + 0,01` для long или `low setup - 0,01` для short;
2. закрытие 5m за этим уровнем;
3. такое закрытие плюс положительная bar-delta для long или отрицательная для short;
4. закрытие сессии за уровнем и по правильную сторону session VWAP;
5. пункт 4 плюс правильный знак дневной delta, RVOL20 не ниже 1,1 и сокращение OI не меньше 0,5%.

Сетка содержит 40 вариантов: 5 подтверждений × срок setup 3/5 × буфер стопа 0,10/0,25 ATR × удержание 3/5 сессий. ATR — средний true range 20 предыдущих завершённых сессий. Внутридневное подтверждение исполняется на открытии следующего 5m-бара; дневное — на открытии следующей сессии. Стоп проверяется раньше выхода по времени. Одновременно разрешена одна позиция, без пирамидинга.

## Лучший pre-holdout вариант

Ни один вариант не прошёл предзаданные ворота. Лучший по pre-holdout рангу вариант ниже перенесён в holdout только для диагностики; он не является устойчивой моделью.

- Setup живёт пять следующих наблюдаемых сессий.
- Long подтверждается первым 5m-закрытием не ниже `high setup + 0,01`; short — не выше `low setup - 0,01`.
- Вход — открытие следующего 5m-бара.
- Long stop — `low setup - 0,10 × ATR20`; short stop — `high setup + 0,10 × ATR20`, с округлением наружу до шага 0,01.
- Вход отменяется, если дистанция до стопа неположительна или больше 3 ATR.
- Выход — защитный стоп либо закрытие последнего 5m-бара пятой сессии удержания; сессия входа считается первой.

## Решение

Модель отклонена для отдельного forward-пилота. Причины: 0 из 40 вариантов прошли ворота, два из трёх fold отрицательны, результат без лучшей сделки отрицателен, соседние параметры неустойчивы, long-правила систематически проигрывают, locked holdout отрицателен и существенно хуже frozen EMA 3/38.

Полные приватные артефакты, включая все сделки и все holdout-сигналы 40 вариантов, хранятся на сервере в `/home/trader/moex_bot/data/research/usdrubf_multiday_reversal_20261110/`. В публичный репозиторий входят код воспроизведения, протокол, агрегаты и список дат сигналов без сырого рыночного массива.
